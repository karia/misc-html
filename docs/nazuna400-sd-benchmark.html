nazuna400 microSD交換後のベンチマーク

Raspberry Pi 400 / 測定日 2026-11-19 / 交換日 2026-11-01

結論

交換による速度の向上は確認できなかった。実運用のI/Oで比べると、書き込み1回あたりの待ち時間は中央値で約8倍に伸びている。

交換後17日間、カーネルログにI/Oエラーは出ていない。交換の効果は速度ではなく信頼性の回復にある。

交換後はjournalの永続化を有効にしたため、書き込みが小さく頻繁になっている。比較条件は揃っておらず、悪化分のすべてがカードの差とは限らない。

測定方法

fio 3.39で、ルートファイルシステム上の1GiBのファイルに対して実行した。各テストは20秒（ウォームアップ2秒を除く）。

[global]
size=1g
direct=1
ioengine=libaio
runtime=20
time_based
ramp_time=2
stonewall
# 以下は各ジョブの設定を1行に要約したもの
[seq-read-1m]      rw=read      bs=1m iodepth=4
[seq-write-1m]     rw=write     bs=1m iodepth=4
[rand-read-4k-qd1] rw=randread  bs=4k iodepth=1
[rand-write-4k-qd1] rw=randwrite bs=4k iodepth=1
[rand-read-4k-qd16] rw=randread  bs=4k iodepth=16
[rand-write-4k-qd16] rw=randwrite bs=4k iodepth=16

旧カードとの比較には、node_disk_*_time_seconds_totalを完了回数で割った値を1時間ごとに求め、期間ごとの中央値とp95をとった。
