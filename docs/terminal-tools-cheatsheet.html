cmux

cmux

Ghostty ベースの macOS ネイティブターミナル。プレフィックス不要のネイティブショートカット。
すべてのショートカットは 設定 または ~/.config/cmux/cmux.json でカスタマイズ可能。 ターミナルのキーバインドは Ghostty の設定（~/.config/ghostty/config）を参照します。 記号: ⌘=Command ⌥=Option ⌃=Control ⇧=Shift

herdr

herdr

ターミナル内で動く agent multiplexer。tmux 風のプレフィックス方式。マウス操作も可能。
プレフィックス方式: デフォルトのプレフィックスは ctrl+b。 プレフィックスを押して離してから、次のキーを押します（例: ctrl+b → c で新規タブ）。
すべてのバインドは config.toml で変更可能。prefix? で有効なバインド一覧を表示。 herdr config reset-keys でデフォルトに戻せます。

lazygit

lazygit

ターミナル用の Git TUI。パネル間を Tab / 数字キーで移動し、選択項目に対しキーを押す。
パネル（Files / Branches / Commits / Stash など）を選択し、対象項目にカーソルを合わせてキーを押します。 ? でその画面のキーバインド一覧、Esc でキャンセル/戻る。 キーバインドは ~/.config/lazygit/config.yml でカスタマイズ可能。
